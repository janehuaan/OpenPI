# 观色

中国古典配色交互展示页。使用同一套生产力产品界面，对比八组颜色系统在背景、表面、文字、边框、按钮、状态和数据可视化中的实际表现。

直接在浏览器中打开 `index.html`，不需要安装依赖或启动开发服务器。

## 包含主题

### 中国古典
- 月白 · 黛青 · 朱砂（宋韵）
- 天青 · 赭石 · 米白（汝窑）
- 石青 · 藤黄 · 墨色（丹青）
- 竹青 · 藕荷 · 象牙白（闺雅）
- 玄青 · 霁蓝 · 赤金（夜宴）
- 胭脂 · 鸦青 · 月白（宫墙）
- 松花 · 苍绿 · 檀色（山林）
- 绛紫 · 雪青 · 银灰（云锦）

### 现代简约
- 纯白冷灰（极简）
- 暖灰亚麻（现代）
- 深空暗银（暗色）
- 雾灰暖金（轻奢）
- 冰蓝月影（清新）
- 墨绿琥珀（自然）
- 炭灰珊瑚（现代）
- 黑曜紫晶（暗色）

色值为面向数字界面的适配值，并非历史颜料或文物颜色的唯一标准。
